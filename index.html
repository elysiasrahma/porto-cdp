Latar Belakang & Fokus Backend

Saya merupakan lulusan S1 Teknik Informatika dengan fokus utama pada perancangan arsitektur backend dan integrasi sistem. Perjalanan saya di dunia pemrograman didorong oleh ketertarikan mendalam terhadap bagaimana data diproses, diamankan, dan dialirkan di balik layar agar sebuah aplikasi dapat berjalan dengan stabil dan andal.

Saya senang menyelesaikan tantangan seputar pemodelan basis data yang rapi, pembuatan endpoint REST API yang konsisten untuk konsumsi web maupun mobile, serta penyusunan alur bisnis (business logic) yang mudah dipelihara.
